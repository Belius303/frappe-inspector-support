# Public Changelog

Frappe Inspector is released across several surfaces. Version numbers can differ between the JetBrains plugin, VS Code extension, CLI and MCP server.

## 1.1.5 — VS Code and Cursor

- Added the interactive DocType relationship graph.
- Added app and module groups, Link and child-table filters, pan, zoom and layout controls.
- Added navigation from graph nodes and relations to their JSON source.
- Added explicit visibility for missing relation targets.
- Improved purchase, download and cross-platform documentation.

## 1.1.4 — CLI, MCP, VS Code and Cursor

- Published CLI `@frappe-inspector/cli` and MCP server `@frappe-inspector/mcp` version 1.1.4 on npm.
- Hardened Universal Pro activation, refresh and product-bound certificate handling.
- Added persistent CLI license management with activate, status, refresh and deactivate commands.
- Kept environment-variable and license-file credentials ephemeral.
- Fixed stale local credentials incorrectly making a fresh editor profile appear Pro.

## 1.1.3

- Added Universal Pro support across VS Code, Cursor, CLI, MCP and GitHub Actions.
- Added product-bound signed certificates and cross-platform release artifacts.

## 1.1.2 — VS Code and Cursor

- Added the Universal Pro license center.
- Added subscription, certificate and device status.
- Added device deactivation, account access and billing-portal commands.
- Added an allowlisted Sandbox endpoint for controlled activation testing.

## 1.1.1

- Added Universal Pro account management and passwordless billing access.
- Added hardened offline certificate behavior.
- Prepared the isolated production licensing service.

## 1.1.0

- Added the shared cross-platform analysis core and stable report contract.
- Added the Frappe Inspector CLI and local MCP server.
- Added the VS Code and Cursor extension.
- Added the GitHub Action with annotations, job summaries and pull-request blocking.
- Added effective Custom Field and Property Setter schema overlays.
- Added Markdown, JSON and SARIF reports.
- Added Git-ref migration checks for removed references, Link targets, required defaults, type changes and unique fields.
- Added offline-signed Universal Pro licensing for non-JetBrains products.

## 1.0.2 — JetBrains

- Locked Pro features behind JetBrains Marketplace licensing in public IDE runs.
- Added the public support and issue-tracking repository.
- Added the proprietary Developer EULA metadata for the private-source freemium release.
- Updated Marketplace feature copy to match implemented Community and Pro features.

## 1.0.1 — JetBrains

- Added JetBrains Marketplace freemium product metadata.
- Set the plugin vendor metadata to Mohamed Tazi Hnyine.

## 1.0.0 — JetBrains

- Added advanced Frappe source inference.
- Added field-level gutter navigation.
- Added clustered graph layout.
- Added IntelliJ Platform test coverage.

See [GitHub Releases](https://github.com/Belius303/frappe-inspector-support/releases) for downloadable artifacts and release-specific notes.
